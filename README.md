This project is a React-based web application enhanced with GSAP (GreenSock Animation Platform) to create smooth, modern animations. It features multiple sections such as Navbar, Hero, Cocktails, Abouts, Arts, Menu, and Contact, each brought to life with engaging motion effects.


✨ Features

🎨 Hero Section Animations – text reveals with GSAP SplitText

📜 Scroll-based Animations – powered by ScrollTrigger

🖼️ Parallax-like Effects – depth and motion in About & Arts sections

📋 Smooth Menu Animations – clean transitions between sections

⚡ Responsive UI – works across desktop & mobile


🛠️ Tech Stack

React.js

GSAP (ScrollTrigger, SplitText)

CSS (tailwind.css)
